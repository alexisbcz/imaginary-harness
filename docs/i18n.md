# Languages

The web app speaks English and French. It follows the browser's language until the user picks one, from **EN/FR**
next to their name in the sidebar or from ⌘K → **Change language**. The choice is kept in the browser.

## Writing text

Every string people read lives in `src/web/locales`, one file per area and language:

```
src/web/locales/en/newsletter.ts   the English source
src/web/locales/fr/newsletter.ts   its French translation
```

```tsx
import { useTranslation } from "react-i18next";

const { t } = useTranslation("newsletter");
<Button>{t("posts.newDraft")}</Button>
<p>{t("posts.scheduledFor", { time })}</p>   // "Goes out {{time}}"
<p>{t("ideas.count", { count })}</p>          // ideas.count_one / ideas.count_other
```

- Keys are checked by `tsc`, so an unknown key fails the build. The French file is typed with the English file's
  shape, so a missing translation fails the build too.
- Write one key per full sentence, with `{{placeholders}}`. Don't stitch fragments together, because word order
  differs from one language to the next. Use `<Trans>` when a sentence holds an element (`<code>`, a link).
- Format dates and numbers with `intlLocale()`, and pass `dateLocale()` to date-fns, both from `@/lib/i18n`.
- Outside React, call `i18n.t("ns:key")` when the text is needed, never when a module loads.
- Shared words (Cancel, Save, Delete…) live in the `common` namespace.

## The check

```sh
bun run i18n:lint
```

It lists every string a person would read that does not go through `t()`: JSX text, the attributes people read
(`placeholder`, `title`, `aria-label`, `alt`, `label`, `tooltip`…), strings shown from JSX expressions, labels in
config objects, and error messages. It exits with 1 when it finds any, so it can run in CI. It is built on Babel's
parser (`scripts/i18n-lint.ts`) and tested in `scripts/i18n-lint.test.ts`.

It skips what is code rather than text: class names, ids, keys, URLs, comparisons, imports, `t()` keys and
`console` calls. It also skips strings made only of brand and technical names: TikTok, LinkedIn, Substack, SQL,
SMTP and the rest of `BRANDS` in the script. For a deliberate exception, put `i18n-ignore` and the reason on the
line, or on the line before:

```tsx
{/* i18n-ignore: the language codes read the same everywhere */}
{next.code}
```

Messages the server sends (API errors) are not translated yet. The agents already answer in the user's language.

## Adding a language

Add `src/web/locales/<code>/*.ts`, typed like `fr`, and register it in `src/web/locales/index.ts` (`resources` and
`LANGUAGES`). `tsc` lists every missing key.
